# DevOps Production-Style Incident Reports

Hands-on DevOps incident simulations covering troubleshooting, root-cause analysis, service recovery and preventive actions.

## Skills Demonstrated

- Linux troubleshooting
- Docker container management
- Docker networking and port mapping
- Application debugging
- Log analysis
- Root-cause analysis
- Service recovery
- Git and GitHub documentation

| Incident | Topic | Status |

## Lab Environment

- Ubuntu 22.04 (WSL2)
- Docker
- Flask
- Git and GitHub

Build practical troubleshooting skills through realistic DevOps incident simulations and document the investigation, recovery and lessons learned.
